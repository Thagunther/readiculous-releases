# Readiculous

A PDF reader and editor for Windows — read, organise, annotate, edit, search, export and print PDFs,
in English and Arabic.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

- **Readiculous-Setup-x.y.z.exe** — the installer. It installs for you only (no administrator rights needed),
  adds a Start menu shortcut and can offer Readiculous for opening PDFs. The first time, Windows may say
  *“Windows protected your PC”*: click *More info → Run anyway*.
- **Readiculous-x.y.z-portable.zip** — unzip anywhere (a USB stick works) and run `Readiculous.exe`.
  Nothing is installed.
- **SHA256SUMS.txt** — the fingerprints of both files.

Readiculous checks this page once a week (you can change that in *Settings → Updates & privacy*). When a new
version is out it downloads it, checks it against its published fingerprint, and offers *Restart and
update* — nothing is installed without your click.

## Privacy

If you agree when Readiculous first asks, it sends an anonymous check-in once a week: a random number for
your copy, the Readiculous version, the Windows version and the language. Never your name, your files or
anything in them. You can turn it off any time in *Settings → Updates & privacy*.
